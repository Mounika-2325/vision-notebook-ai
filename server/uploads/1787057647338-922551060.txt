2.Non-empty dict
===================
==> a non empty dict is on, which contains elements and whose lenght is > 0(zero)

syntax
======
dictobj={key1:val1,key2:val2,.....,key(n):val(n)}

examples
==========
>>> d2={"python":"rs","C":"dennis","java":"james"}
>>> print(d2,type(d2))
{'python': 'rs', 'C': 'dennis', 'java': 'james'} <class 'dict'>
>>> len(d2)
3

===================================================
sybtax for addng  (key,value) to the empty/non-empty dict object
=======================================================
dictobject[key1]=val1
dictobject[key2]=val2
.
.
.
.
.
dictobject[key-n]=val(n)

here key1,key2,,...keyn are values of key
here val1,val2,....valn are values of value

examples 
=========
>>> d1={}
>>> print(d1,type(d1))
{} <class 'dict'>
>>> len(d1)
0
>>> d1["branch"]="ece"
>>> print(d1,type(d1))
{'branch': 'ece'} <class 'dict'>
>>> d2[100]=1.5
>>> print(d1,type(d1))
{'branch': 'ece'} <class 'dict'>
>>> d1[100]=1.5
>>> print(d1,type(d1))
{'branch': 'ece', 100: 1.5} <class 'dict'>
>>> d1[400]=121
>>> print(d1,type(d1))
{'branch': 'ece', 100: 1.5, 400: 121} <class 'dict'>
>>> d1[100]=463
>>> print(d1,type(d1))
{'branch': 'ece', 100: 463, 400: 121} <class 'dict'>

>>> print(d1,type(d1))

=============
1.clear()
==============
==> this function is used for removing all the values from Dict object
==> when we call this function on empty dict objct then we get Space or None as a Result 

syntax
=======
dictobject.clear()

exampales 
==========
>>> d1={10:1.2,20:2.2,30:2.3,40:4.4}
>>> print(d1,type(d1),id(d1))
{10: 1.2, 20: 2.2, 30: 2.3, 40: 4.4} <class 'dict'> 2358869231232
>>> len(d1)
4
>>> d1.clear()
>>> print(d1,type(d1),id(d1))
{} <class 'dict'> 2358869231232
>>> len(d1)
0
>>> print(d1.clear())
None
>>> print({}.clear())
None
>>> print(dict().clear())
None
