=========

==> f will supply the values to variables or place holders

==> this syntax will display message cum value with letter 'f'

examples
========
>>> a=10
>>> print(f"value of a={a}")
value of a=10
>>> print(f"value of a = {a}")
value of a = 10
>>> print(f"{a} is the value of a")
10 is the value of a
>>> print("{a} is the value of a")
{a} is the value of a

>>> a=10
>>> b=20
>>> c=a+b
>>> print(f"sum of {a} and {b} = {c}")

==> in python programming, we use 3 types of format specifiers
1. %d is used for representing integer data
2  %f is used for representing float data
3  %s is used for representing str data 

==> if we dont have format specifiers for nay value then that value must be converted into str by using str() and use %s

examples
========
>>> a=10
>>> print("val of a=%d" %a)
val of a=10
